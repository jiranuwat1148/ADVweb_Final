## รูปแบบหน้าจอ

- **ภาพรวม:** เมนูด้านซ้าย ตัวเลขสรุปออเดอร์ กล่อง ไรเดอร์ และกำไร แผนที่เส้นทางแยกสี ใบงานไรเดอร์ที่เห็นได้ 6 ใบ ปุ่มคำนวณใหม่ และสรุปต้นทุนก่อนยืนยันแผน
- **ออเดอร์:** สรุปยอด ค้นหา กรองสถานะ จำลองออเดอร์ และตารางที่แสดงจำนวนกล่อง ยอดเงิน สถานะ และรายการแก้ไข/ลบ
- **ลูกค้า:** ค้นหาลูกค้า รายการลูกค้า และรายละเอียดที่อยู่ เบอร์โทร พิกัดบ้าน และปุ่มเปิดแผนที่
- **ไรเดอร์:** แสดงเลขใบงาน จำนวนอาหารที่ต้องหยิบ เวลาออกส่ง และจุดส่ง 3 จุดเรียงลำดับ พร้อมปุ่มเปิดแผนที่และโทร

แผนที่ใน Figma เป็นภาพจำลองที่สร้างจากเวกเตอร์แก้ไขได้ พิกัดและเส้นทางแสดงแนวทางจัดวางหน้าจอ มีข้อความ “ข้อมูลจำลอง” และ “เส้นทางประมาณ” กำกับไว้ การใช้งานจริงควรรับระยะทาง เวลา และ GeoJSON จาก backend

## Typography และส่วนประกอบร่วม

- ภาษาไทย: **Noto Sans Thai**, style ที่ตรวจพบจริงคือ Regular, Medium, SemiBold และ Bold
- ตัวเลขและภาษาอังกฤษ: **Manrope**, Regular และ Bold
- หัวข้อหลัก 28 px / line height 42 px
- หัวข้อส่วน 18 px / line height 28 px
- เนื้อหาและปุ่ม 14 px / line height 24 px
- ข้อความรอง 12 px / line height 20 px
- ตัวเลขสรุป 32 px / line height 44 px
- เครื่องหมายเงินบาทใช้ Noto Sans Thai เพื่อให้แสดง `฿` ได้ครบ

มี component สำหรับ Button (Primary/Secondary), Stat Card, Rider Card, Input และ Nav Item ที่แก้ข้อความผ่าน component property ได้ โดยหน้าจอใช้ instance ของส่วนประกอบเหล่านี้

## สถานะการตรวจสอบ

ตรวจภาพเต็มของทั้ง 4 หน้าจอและชุด component แล้ว ข้อความและลำดับชั้นเป็น editable layer ใช้ auto layout สำหรับกลุ่มเนื้อหา และใช้ vector สำหรับแผนที่ หน้าจอทั้งหมดมี **0 image fills** จึงไม่มีการใช้ภาพหน้าจอทั้งหน้าแทนองค์ประกอบ UI

ตรวจชื่อ font family แล้วเป็น Noto Sans Thai และ Manrope ทั้งหมด หลังตรวจภาพได้แก้การแสดงเครื่องหมายเงินบาทบนการ์ดตัวเลขสองตำแหน่ง และปรับหน้าลูกค้าให้แสดงเฉพาะหมุดบ้านที่เลือก หน้าลูกค้าผ่านการตรวจภาพหลังแก้ไข

**ข้อจำกัดการตรวจสอบ:** Figma MCP ของบัญชี Starter / View ถึงจำนวนเรียกที่อนุญาตระหว่างขอภาพหลังแก้เครื่องหมายเงินบาท จึงยังไม่ได้ตรวจภาพหลังแก้ของหน้าภาพรวมและออเดอร์อีกครั้ง การแก้ไขสองตำแหน่งสำเร็จและมี Node ID ยืนยันจากเครื่องมือ แต่ควรเปิดใน Figma เพื่อตรวจภาพสุดท้ายด้วยตนเอง

ไฟล์ Figma เป็นแบบหน้าจอแก้ไขได้ การทำงานจริง เช่น CRUD การคำนวณ การกรอกเลขใบงาน และการนำทาง ต้องใช้แอป Angular และ backend
